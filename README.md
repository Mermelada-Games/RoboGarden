# RoboGarden

## Description

**RoboGarden** is a cooperative *party game* where **two players** control small **gardener robots**.  
Their goal is to **manage and organize all the seeds** in a large garden, ensuring that each seed reaches its correct location to **grow and bloom**.

To achieve this, players must **coordinate strategically**, as many tasks require both of them to work together and depend on each other to complete them.
